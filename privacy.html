プライバシーポリシー

golfordance-yt（制定日 2026年11月9日）

1. このアプリについて

golfordance-yt は、YouTube チャンネル @golfordance_lab の運営者が、自分のチャンネルの集計値を見るためだけに使う道具です。運営者以外の利用は想定していません。

2. 取得する情報

運営者本人が Google の画面で許可した場合に限り、次の情報を読み取ります。

  • YouTube Analytics API：動画ごとの再生数、視聴時間、平均視聴率、登録者の増減、高評価・コメント・共有の数、視聴者維持率、表示回数とクリック率などの集計値
  • YouTube Data API：自分のチャンネル名と、公開した動画のタイトル・公開日・長さ・説明文

視聴者一人ひとりを特定できる情報は取得しません。許可の範囲は読み取り専用（yt-analytics.readonly、youtube.readonly）です。

3. 使い道

取得した集計値は、運営者が自分の動画の出来を振り返り、次の動画づくりに生かすためだけに使います。広告、販売、第三者への提供には使いません。

4. 保存と共有

取得した集計値と許可の情報（更新用の鍵）は、運営者のパソコンの中にだけ保存します。第三者に渡したり、公開したりしません。

5. 許可の取り消し

Google アカウントの「セキュリティ」→「サードパーティ製のアプリとサービス」から golfordance-yt のアクセス権を削除すると、それ以降は情報を読み取れなくなります（Google アカウントの設定）。

6. Google のポリシーとの関係

このアプリによる Google API から受け取った情報の使用は、Google API Services User Data Policy（限定的使用の要件を含む）に従います。YouTube の情報の扱いには YouTube 利用規約 と Google プライバシー ポリシー も適用されます。

7. お問い合わせ

このポリシーについてのお問い合わせは、YouTube チャンネル @golfordance_lab の運営者までご連絡ください。
